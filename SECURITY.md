# Security

Report a vulnerability privately, through the repository's Security tab (Report a vulnerability). Please don't open a public issue for one.

The switchboard listens to a microphone and passes what it hears to Claude Code sessions that can run commands. Anything that lets anyone but me speak into the voice room, reach a session through the switchboard or answer a permission prompt is in scope. So is anything that publishes a transcript or a credential.

Only `main` is supported. There are no releases yet.
